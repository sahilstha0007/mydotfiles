Orientation

0.1The one big idea

Neovim is modal: the same key does different things depending on the mode you are in. That is the whole trick, and it is why the first week feels alien and everything after it feels fast.

Normal
Your home base. Every key is a command — j moves, d deletes, p pastes. You live here most of the time.
Insert
Typing. Enter it with a purpose, type, leave. Escaping back to Normal is the habit that makes you fast.
Visual
Selecting. Normal with a selection: keys now act on the highlighted range.
Command
The : line. Save, quit, search-replace, run ex commands, open plugins.

Rule one: when your thought is typed, press Esc. In this config Esc also clears the search highlight and dismisses stray floating windows, so it is always a safe press.

0.2Your first hour, in order

Do these five things in sequence. Each one is useful on its own, and together they cover most of daily editing.

1 · 10 min
Open a file with Space+f+f. Move with hjkl, w, gg G. Type i, write a sentence, press Esc, save with :w. Repeat until escaping is a reflex.
2 · 10 min
Learn the verb + noun grammar on one word: ciw change it, daw delete it with a space, yiw yank it, then viw select it. Press . to repeat your last change five times.
3 · 15 min
Press Space and read the which-key menu out loud. Open a second file, switch with Space+,, split with Space+|, move between windows with Ctrl+w then h/l.
4 · 15 min
In a real project: Space+s+g to grep, Space+c+r to rename a symbol, Space+c+f to format, ]d to walk diagnostics. This is the loop you will use all day.
5 · 10 min
Run something: Space+r+c in a script, then in tmux press Prefix+e on an error to land back in the file at the right line.
The rule that matters

Never look up a key you just used. Look up the next key you need, then use it until it is boring. Which-key is the menu; this page is the map.

I

Modes

1Normal mode: moving

Movement is the first skill, and relative line numbers exist so you can count jumps by sight instead of guessing.

h j k l
Left, down, up, right — arrows on the home row.
w b e
Word start / back / end. W B E does the same by whitespace, skipping punctuation.
0 $ ^
Line start, line end, first non-blank character.
gg G · 12G
Top, bottom, line 12.
%
Jump between matching brackets.
fx tx ; ,
Jump to / just before the next x; ; repeats forward, , backward.
/pat n N
Search, next, previous. Esc clears the highlight here.
* #
Search the word under the cursor — the fastest “where else is this used”.
C-d C-u
Half-page scroll. zz centres the cursor line.
C-o C-i
Back / forward through the jumplist — browser history for your cursor.
your config · lua/options.lua
vim.opt.relativenumber = true   -- jump by sight
vim.opt.ignorecase     = true   -- /user finds "User"
vim.opt.smartcase      = true   -- /User is case-sensitive
vim.opt.scrolloff      = 10     -- keep the cursor off the edges

Because smartcase is on, lowercase patterns match any case and a capital letter makes the search exact.

2Normal mode: editing

The grammar is verb + noun. d deletes, c changes (delete, then insert), y yanks — each followed by a motion or a text object. Counts multiply: 3ciw changes the next three words.

x · X
Delete the character under / before the cursor.
dd yy p P
Cut line, copy line, paste after, paste before.
u · U · C-r
Undo, redo, native redo. Undo survives restarts here (undofile).
.
Repeat the last change — the single most valuable key in the editor.
gcc · gc{motion}
Toggle a comment on the line, or over a motion. Works in Visual too.
J
Join the next line onto this one.
guu gUU g~
Lowercase, uppercase, flip case — over a motion or a line.
= · gg=G
Re-indent this line / the whole file.
> <
Indent / outdent; in Visual the selection is kept so you can repeat.
Alt-j Alt-k
Move the current line or selection down / up.

3Insert mode

Insert is for typing, not for editing. Get in, type, get out.

i a · I A
Before / after the cursor; start / end of line.
o O
New line below / above, straight into Insert.
s S · cc
Replace a character, a line, a line keeping indent.
C-l
Custom: skip past a closing bracket, quote or comma instead of typing it.
C-w C-u
Delete the previous word / to line start while typing.
C-t C-d
Indent / outdent the current line without leaving Insert.
C-r "
Paste a register inline — C-r + inserts the system clipboard.

4Visual mode

Visual is Normal plus a highlight. Select, then act.

v · V · C-v
Character, line, block selection.
d c y
Delete, change, yank the selection.
H L J K
Custom: move the selected block left, right, down, up.
gv
Re-select the last selection.
o
Flip the cursor to the other end of the selection.
The superpower

Block edit: Ctrl+v, move down across several lines, press I, type your prefix, Esc. The text lands on every line at once. Select whole file with ggVG, then = to re-indent everything.

5Command mode

:w :q :wq :q!
Save, quit, save-and-quit, quit without saving.
:e file · :e!
Open by name; reload from disk.
:%s/old/new/g
Replace everywhere; add c to confirm each hit.
:10,20d · :.d
Range deletes: lines 10–20, the current line.
:!cmd · :r !cmd
Run a shell command; read its output into the buffer.
q: · q/
Edit and re-run the command or search history.
your config · lua/options.lua
vim.opt.inccommand = 'split'   -- live preview of :s///
vim.opt.splitright = true
vim.opt.splitbelow = true
vim.opt.cmdheight  = 0

Type a substitution and watch the file change as you type it.

III

Editing craft

11Text objects and surround

Text objects target meaning — a word, a quote, a function body — instead of characters. This is the jump from “knowing vim” to “moving through code”.

ciw caw
Change inner / around word.
ci" ci' ci`
Change inside quotes — your daily bread.
ci( ci{ cit
Inside parens, braces, tags. Swap c for d to delete, y to copy.
dip yip
Delete / yank the paragraph.
af if ac ic
Treesitter objects: function and class, outer and inner. Also ab/ib block, aa/ia parameter.
]f [f
Next / previous function.
gsa gsd gsr
Surround: add, delete, replace. gsaiw" wraps the word in quotes.
gsf · gsn
Find the next surrounding pair; set N lines to surround.

12Search and replace

CommandWhat it does
:s/old/new/This line, first match.
:%s/old/new/gWhole file, every match.
:%s/old/new/gcConfirm each hit with y/n/q.
:3,12s/x/y/gOnly lines 3–12. '<,'> is the Visual selection.
:g/foo/dDelete every line containing foo.
:%s/\v(\w+) (\w+)/\2 \1/Swap two words with capture groups.

\v (very magic) makes a pattern read like most regex engines. Across the whole project, prefer Space+s+r — it previews every match before it writes.

13Registers

Every delete and yank lands in a register — named clipboards. That unlocks “yank two things, paste both”.

"
The unnamed register: whatever you last deleted or yanked.
0 – 9
Last ten yanks. "0p pastes your last yank even after a delete.
a – z
Yours: "ayy yanks a line into a, "ap pastes it.
+ *
System clipboard. clipboard=unnamedplus is on, so plain y/p already use it.
_
Black hole: "_dd deletes without clobbering the clipboard.

Browse them with Space+s+", or every yank from this and previous sessions with Space+s+y.

14Marks and jumps

ma · `a 'a
Set mark a; backtick goes to the exact column, quote to the line.
mA · `A
Uppercase marks are global — jump across files.
`` ''
Back to where you were before the last jump.
g; g,
Changelist: the last place you edited, not just moved.
Space sm
Pick a mark from the picker.

15Macros

A macro records keystrokes into a register and replays them — the fix for “I have done this forty times”.

qa … q
Start recording into a; stop.
@a · @@
Replay; replay the last macro again.
100@a
Replay 100 times — it stops harmlessly at the end of the file.

Recipe: go to the first line, qa, make the edit, press j so the next replay lands on the next line, q. Then 100@a. To fix a broken macro, paste it with "ap, edit the text, and "ay$ to save it back.

24Plugins and config

Every plugin is a lazy.nvim spec: one file under lua/plugins/<category>/, imported by lua/lazy-init.lua.

Space l
Lazy actions menu — sync, update, clean, check, profile, health, log.
:Lazy update · clean
Update everything; remove specs you deleted.

Adding a plugin — the three-step ritual

  • Create lua/plugins/<category>/<name>.lua returning a spec table.
  • Add { import = 'plugins.<category>.<name>' } to the spec list in lua/lazy-init.lua.
  • Restart Neovim. To remove: delete the file, the import line, then run :Lazy clean.
your config · boot order
vim.g.mapleader = ' '   -- 1. leader before any map loads
require 'globals'       -- 2. mise PATH, diagnostics, netrw off
require 'options'       -- 3. every vim.opt
require 'keymaps'       -- 4. custom keys
require 'lazy-init'     -- 5. bootstrap lazy + all specs

If the leader is set after a keymap is parsed, those bindings land on the default \ instead. That is why it is set first, and reaffirmed in globals.lua.
