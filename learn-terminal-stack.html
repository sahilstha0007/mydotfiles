01

Universal Navigation & Shared Contracts

Instead of having separate keys for terminal windows, multiplexer splits, and editor panes, your setup binds them to shared, universal signals.

1. The Seamless Directional Jump (Ctrl + h/j/k/l)

Your cursor travels across Kitty window splits, Tmux panes, and Neovim editor windows using the exact same muscle memory:

Shortcut Boundary Engine / Handler Description
Ctrl + h Focus Left pass_keys.py / tmux.nvim Moves left across Neovim splits, jumping into Tmux/Kitty panes at boundaries.
Ctrl + j Focus Down pass_keys.py / tmux.nvim Moves down into adjacent splits or terminal runner panes.
Ctrl + k Focus Up pass_keys.py / tmux.nvim Moves up from terminals back into editor splits.
Ctrl + l Focus Right pass_keys.py / tmux.nvim Moves right across editor splits.
The Directional Fallback
If an interactive TUI catches Ctrl chords, Kitty provides unconditional window navigation with Ctrl + Shift + Arrows, and Tmux provides Prefix + H/J/K/L.

2. Split Shape Symmetry

The visual split line matches your key across all layers:

  • Space| (Neovim) and Prefix| (Tmux) create a vertical split (side-by-side).
  • Space- (Neovim) and Prefix- (Tmux) create a horizontal split (stacked).

Tmux hosts your persistent sessions, long-running processes, Docker containers, and test watchers across reboots.

Filesystem as a Buffer: Oil.nvim

Press - to open the parent directory or SpaceO for a floating window. You can rename, copy, move, and delete files using standard Vim commands (like ciw, dd, p), then press :w to apply changes to the operating system!

Quickfix Triage Queue

After piping search results into the quickfix list (Ctrl + q):

  • Use ]q and [q to step through matches with automatic wrap-around.
  • Press dd (or select rows in visual mode and hit d) to delete items you don't want to edit.
  • Run :Cfilter <pattern> to filter matches, then run :cfdo %s/old/new/ge | update to perform atomic replacements across all files!
06

Daily High-Velocity Playbooks (Muscle Memory Drills)

playbooks

Combine keystrokes across all layers into fluid muscle memory routines for common engineering scenarios.

Drill 1: 5-Second Full-Stack Workspace Spin-Up

1. Open terminal → Press Prefix + f (or Ctrl+Shift+o in Kitty) → Type project name → Enter.

2. Inside Neovim: Press SpaceSpace → Jump to file.

3. Create test split: Press Prefix + - → Run watcher → Press Ctrl + k to jump back to editor.

Drill 2: Error Jump → Blame → Test Run

1. When a test fails: Press Prefix + e in Tmux (or Ctrl+Shift+p>n in Kitty).

2. Select the error line from fzf preview → lands cursor right on that line in Neovim.

3. Press gl for floating diagnostic or SpacegB for full Git blame.

4. Fix issue → Press Spacerc to rerun file in tmux split!

Drill 3: Surgical AST Editing Without Arrows or Mouse

1. 2D jump: Press s then 2 characters (Flash.nvim) to land on any target on screen.

2. Edit parameter: Press cia (Change Inside Argument) → type new type.

3. Hop delimiter: In insert mode, press Ctrl + l to skip past closing brackets/quotes without touching arrows.

4. Surround: In normal mode, press gsaiw" to wrap word in quotes, or gsr"' to swap double quotes to single quotes.
