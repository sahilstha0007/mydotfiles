Your terminal is an instrument.

WezTerm and Kitty draw pixels. tmux owns sessions, windows and panes. zsh gets you places. Neovim edits. This page is how the five layers cooperate — and which one wins when two of them claim the same key.

00 · Overview

What sits on what

Read top to bottom: a keystroke enters at layer 1 and gets claimed by the outermost layer that binds it. Everything confusing about this setup follows from that one sentence.

01
emulator
Kitty (daily driver, SUPER+RETURN) and WezTerm (dev workstation + theme writer, SUPER+SHIFT+RETURN). Wayland, GPU, fractional scaling.
02
multiplexer
tmux 3.8, prefix C-a, shared socket at ~/.cache/tmux so both emulators attach to one server. Sessions survive the window.
03
shell
zsh + oh-my-posh + atuin + zoxide + fzf. ~66 ms startup, z <name> to jump, Ctrl+R for history.
04
editor
Neovim 0.12.6 — lazy.nvim, snacks picker, native LSP, blink.cmp, and a tmux-backed code runner.
05
tuis
lazygit · lazydocker · yazi · btop — all reachable as 90% floating popups without leaving the current pane.
The one rule

One leader per layer, and they never collide because they live at different depths: WezTerm Alt+Ctrl+Space, tmux C-a, nvim Space. Inside nvim, Space is always nvim's — the inner app beats the outer for a shared leader character.

04 · Multiplexer

tmux: sessions that outlive windows

Prefix is Ctrl+a. Live tables: 118 prefix keys, 54 root keys, 21 of those root keys on Alt. State is snapshotted on detach and restored on attach.

Send a literal Ctrl-a

Press Ctrl+a twice. That is bind C-a send-prefix — zsh's beginning-of-line still works, and nested tmux still works.

The filesystem is a buffer

- opens the parent directory in Oil. Rename, copy, move and delete with ordinary Vim commands (ciw, dd, p), then :w writes the changes to disk. Space+O gives you the same thing in a float.

Quickfix triage

Send search results to the quickfix list, then ]q/[q walk them with wrap-around. Delete entries you will never touch with dd, narrow with :Cfilter <pattern>, and finish with :cfdo %s/old/new/ge | update for an atomic edit across every file left in the list.

06 · Muscle memory

Three drills worth repeating

Each drill chains layers on purpose. Run them until the keys stop being a lookup.

Drill 1 · 30 seconds

Spin up a project workspace

  1. Prefix f (or Kitty Ctrl+Shift+o) — type the project, Enter.
  2. In Neovim: Space Space → jump to a file.
  3. Prefix - for a runner pane, then Ctrl+k to come back.
  4. Space r c — run the file into that pane.
Drill 2 · failure loop

Error → blame → fix → rerun

  1. A test fails. Prefix e (tmux) or Ctrl+Shift+p→n (Kitty).
  2. Pick the error line — it previews, then lands the cursor on that line.
  3. Space g B for full blame on the line you are about to change.
  4. Fix it, then Space r c to rerun without leaving the buffer.
Drill 3 · no arrows, no mouse

Surgical AST editing

  1. s then two characters — Flash lands anywhere visible on screen.
  2. cia changes inside the function argument you landed on.
  3. Ctrl+l in insert mode hops past the closing bracket instead of typing it.
  4. gsaiw" wraps the word in quotes; gsr"' swaps them.
